# Supplementary Material: Reproducibility Artifacts

This package contains genuine files retained from, or regenerated by rerunning,
the published experimental protocol. The export tool never synthesizes training
curves, client partitions, or hardware telemetry.

## Directory overview

- `partitions/`: serialized client-to-sample assignments, including the seed,
  index basis, partition parameters, and SHA-256 digest;
- `run_logs/`: per-round, per-seed training records;
- `power_traces/`: timestamped hardware telemetry and measurement summaries;
- `schedules/`: fixed client-participation schedules shared by compared methods;
- `configs/`: shared protocol, method hyperparameters, and tuning records;
- `reported_results/`: machine-readable records used in the appendices;
- `metadata/`: source commit and artifact metadata.

For a fixed dataset, client count, partition type, and seed, the same partition
file and client schedule are reused across all compared methods. Seeds 20, 21,
and 22 are distinct repeated experimental realizations. The expected partition
settings are CIFAR-10 P1/P2 with 3/5 local classes, CIFAR-100 P1/P2 with 10/20
local classes, CIFAR D1/D2 with Dirichlet alpha 0.3/0.6, and Tiny-ImageNet D1
with Dirichlet alpha 0.1.

## Per-round logs

Each log contains `round`, `test_accuracy`, `train_objective`, `mfg`, `hfr_tau`,
`downlink_bytes`, `uplink_bytes`, `cumulative_serialized_bytes`, and
`single_device_elapsed_seconds`. Byte counts are measured serialized payloads.
The elapsed value is serialized simulator compute time and is not described as
distributed wall-clock time.

## Power traces

Power is sampled at the device-supported cadence, normally requested at 100 ms.
Each record states `power_scope`; GPU-board and whole-board measurements are not
interchanged. Energy is integrated from the actual timestamps using the
trapezoidal rule:

```bash
python calc_hardware_summary.py
```

## Export

First audit the retained materials:

```bash
python gen_supplementary_export.py --audit-only
```

After every required raw file is present and validated, create the package:

```bash
python gen_supplementary_export.py --output-root supplementary_material
```

The export is refused when any required evidence is missing or malformed. This
includes the exact baseline tuning record and a clean, tagged release commit.
A successful package includes `SHA256_MANIFEST.json` for independent integrity
verification.
