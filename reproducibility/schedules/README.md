# Deterministic rerun schedules

These schedules are generated by `fedradr.reproducibility.make_client_schedule`
with NumPy's `default_rng(seed)`. Within a setting and seed, every compared
method must consume the exact same file.

They are release schedules for deterministic reruns. Until compared with files
retained from the original experiment host, they must not be described as
recovered historical schedules for the primary campaign.
